## EventFlow
EventFlow is a webhook delivery platform built with Django REST Framework.

It allows users to register webhook endpoints and manage them througn a REST API, 
The platform is designed to deliver events reliably, handle failed requests,
and track delivery attempts.

# Tech Stack
 *Python
 *Django & Django REST Framework
 *PostgreSQL
 *Redis
 *Celery
 *Docker

# Features
 *Webhook endpoint managment
 * Secure API authentication
 *Event delivery
 *Automatic
 *HMAC signatures
 *Delivery history
